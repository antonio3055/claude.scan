================================================================
RELIABILITY UNDER SEVERAL LANES — what was checked, not assumed
================================================================
  - Every file is read exactly once; no two lanes take the same file.
  - Lanes really overlap, and never more than the lane count.
  - At one lane the queue is byte-for-byte the old sequential queue, in order.
  - A file that fails in one lane does not stop the others.
  - A failed file resets only its own lane's OCR worker.
  - Stop ends every lane, and every PDF/OCR worker is terminated within 5 s
    (verified in the real browser, clicking the real Stop button).
  - The good/bad/good queue run still fails exactly the three bad files, drains
    to idle, and leaves 0 workers running (verified in the real browser).
  - The engines are released when the queue goes idle, so an idle scanner holds
    no PDF worker and no Tesseract worker.
